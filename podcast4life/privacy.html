개인정보처리방침

podcast4life (P4L) 자동 게시 파이프라인 · 최종 수정 2026-08-24

이 페이지는 podcast4life(이하 "P4L") 팀이 자체 운영하는 팟캐스트 쇼츠 자동 게시 도구("이 앱")에 대한 개인정보처리방침입니다. 이 앱은 외부 사용자를 대상으로 하는 서비스가 아니라, P4L 제작팀 내부에서만 쓰는 자동화 도구입니다.

적용 범위 — 반드시 읽어주세요. 이 방침은 YouTube 업로드 자동화 도구에만 적용됩니다. 같은 팀이 toowani.com 하위에서 운영하는 다른 서비스 — 예를 들어 팀 내부용 미리보기 사이트 p4l.toowani.com — 는 구글 로그인을 통해 이름·이메일·프로필 사진을 저장하는 등 여기서 설명하는 것과는 다른 별도의 데이터 처리 방식을 사용하며, 이 문서가 다루는 대상이 아닙니다.

이 앱이 하는 일

  • P4L이 자체 제작한 팟캐스트 영상 클립을, YouTube Data API를 통해 P4L 소유의 YouTube 채널에 업로드합니다.
  • 업로드된 영상의 공개 상태(비공개 → 공개)를 나중에 전환합니다.
  • 이 두 가지 외에 YouTube 계정으로 다른 작업(구독 목록 조회, 댓글 관리, 다른 채널의 데이터 접근 등)은 하지 않습니다.

수집하는 정보

  • 이 앱은 Google 계정의 개인정보(이름, 이메일, 프로필 사진 등)를 수집하거나 저장하지 않습니다.
  • OAuth 인증은 오직 YouTube Data API 호출 권한을 얻기 위한 용도로만 사용됩니다.
  • 발급된 OAuth 리프레시 토큰은 P4L의 자동화 실행 환경(GitHub Actions Secrets, 팀 내부 로컬 환경변수)에만 저장되며, 제3자에게 제공되거나 판매되지 않습니다.

권한 철회

Google 계정 — 제3자 앱 액세스 권한 페이지에서 언제든지 이 앱의 접근 권한을 철회할 수 있습니다.

관련 정책

  • 이 앱은 YouTube API Services를 사용하며, YouTube 서비스 약관에 동의함으로써 이를 이용합니다.

Privacy Policy

podcast4life (P4L) automated publishing pipeline · Last updated 2026-08-24

This page describes the privacy practices of the automated podcast-shorts publishing tool ("this app") operated by the podcast4life (P4L) team. This app is an internal automation tool used only by the P4L production team — it is not a public-facing service.

Scope — please read. This policy applies only to the YouTube upload automation tool. Other services the same team operates under toowani.com — for example, the internal preview site p4l.toowani.com — use Google Sign-In to store name, email, and profile photo, following a separate data-handling process not covered by this document.

What this app does

  • Uploads podcast video clips produced by P4L to P4L's own YouTube channel via the YouTube Data API.
  • Later changes the privacy status of previously uploaded videos (private → public).
  • This app performs no other actions on the YouTube account (no reading subscriptions, no comment management, no access to other channels' data).

Information we collect

  • This app does not collect or store any personal information from your Google Account (name, email, profile picture, etc.).
  • OAuth authorization is used solely to obtain permission to call the YouTube Data API.
  • The issued OAuth refresh token is stored only within P4L's own automation environment (GitHub Actions Secrets, internal local environment variables) and is never shared with or sold to any third party.

Revoking access

You can revoke this app's access at any time from Google Account — Third-party apps & services.

Related policies

  • This app uses YouTube API Services and, by using it, agrees to be bound by the YouTube Terms of Service.
